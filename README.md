# Свой тренер

Тренер по технике упражнений: камера телефона или видео → распознавание позы прямо в браузере →
счёт повторов, подсказки голосом, план подходов и подробный разбор каждого повтора. Видео никуда не отправляется.

Открыть: **https://eassvr-max.github.io/svoy-trener/** (на айфоне — в Safari, затем «Поделиться» → «На экран „Домой“»).

Упражнения: приседания, отжимания, выпады, планка.

## Что где

| Файл | Что внутри |
| --- | --- |
| `engine.js` | Движок: признаки по 33 точкам тела (2D + 3D), сглаживание, счёт повторов, оценка техники, голос тренера, план подходов |
| `index.html` | Приложение: камера, разбор видео, отчёт. `build.js` вшивает в него движок → `dist/svoy-trener.html` |
| `test_engine.js`, `synth3d.js` | Проверки движка на синтетическом 3D-человеке (запускаются при каждом изменении) |
| `e2e2.js`, `e2e3.js` | Проверка страницы целиком в браузере (Playwright), запуск вручную |
| `tools/make_voice_pack.py` | Озвучка всех фраз тренера живым голосом (Yandex SpeechKit / ElevenLabs) |
| `calib/` | Скрипты калибровки порогов на реальных видео (сами наборы данных в репозиторий не входят) |

## Откуда пороги

Пороги ошибок подобраны на размеченных видео реальных людей: Mendeley «Multi-View Raw Video Dataset of Seven Fitness Exercises»
(26 человек, правильно/неправильно, три ракурса), Exercise-Correction (планка, выпады) и QEVD-FIT-300k (около 4,4 тыс. клипов
с метками ошибок, съёмка спереди). Цель — ложные серьёзные замечания не больше чем у ~5–10% правильных повторов.

## Локально

```
node test_engine.js   # проверки
node build.js         # dist/svoy-trener.html — открыть в браузере (камере нужен https или localhost)
```
